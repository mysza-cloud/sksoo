# SKSOO — Dark Minimal Club v2.3

To lokalna, nieopublikowana wersja strony SKSOO. `index.html` jest samodzielnym plikiem: zawiera cały wygląd, działanie, treści i grafiki. Można otworzyć go dwuklikiem w przeglądarce, bez instalacji i bez serwera.

## Zawartość

- `index.html` — strona Dark Minimal Club v2.3 z poprawionym położeniem słów „PASJA · SPORT · LUDZIE · SPOŁECZNOŚĆ” oraz ustawieniami kolorystyki. Punktem wyjścia był plik z lokalnego archiwum `SKSOO_INDEX_POBIERZ.zip`; treści i grafiki zachowano.
- `assets/` — kopie dziesięciu grafik osadzonych w HTML, przydatne do późniejszej edycji. Strona nie wymaga tych kopii do działania.
- `check.mjs` — lokalna kontrola spójności pliku i grafik; uruchomienie: `node check.mjs`.

Po rozpakowaniu paczki otwórz `index.html`. Archiwum można także zachować jako kopię całego projektu.

Przycisk **Motyw** w lewym dolnym rogu pozwala wybrać wygląd ciemny, jasny, zielony, beżowy lub granatowy. Wybór zapisuje się lokalnie w przeglądarce jako `sksoo-theme` i nie jest nigdzie wysyłany. Po wyczyszczeniu danych przeglądarki wraca domyślny motyw ciemny.

Wersja zawiera oznaczenie podglądu i znacznik `noindex,nofollow`. Nie została opublikowana. Dalsze zmiany treści lub grafiki należy wykonywać w kopii roboczej i sprawdzić przed publikacją.

Nowe ilustracje utworzono wbudowanym ImageGen: przezroczyste dekoracje w „O nas”, „Jedna pasja” i „Kontakt” oraz trzy ilustracje kart aktualności. Są materiałami poglądowymi, a nie fotografiami wydarzeń SKSOO. Opisy użytych poleceń znajdują się w `GRAFIKI.md`.
